# Blinkit Data Analysis Dashboard

## Project Overview
This project analyzes Blinkit's grocery sales data using Microsoft Excel.
The dashboard provides insights into sales, product categories, outlet types,
outlet locations, and other key business metrics.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Cleaning

## Key Analysis
- Total Sales
- Average Sales
- Number of Items
- Average Rating
- Sales by Item Type
- Sales by Outlet Type
- Sales by Outlet Location
- Sales by Fat Content
- Sales by Outlet Size

## Dashboard
The interactive Excel dashboard was created to analyze sales performance
and identify useful business insights.
